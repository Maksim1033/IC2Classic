Industrial Craft Classic port for **Minecraft Forge 1.20.1**.

This project is an unofficial continuation and port of **Industrial Craft Classic** from Minecraft **1.19.2 Forge** to **1.20.1 Forge**.

The main goal is to preserve the original gameplay, API, mechanics and compatibility while adapting the mod to the newer Minecraft and Forge versions.

## Features

- Full Industrial Craft Classic experience for Forge 1.20.1
- Preserved machines and energy systems
- Preserved items, blocks and mechanics
- Updated Forge API compatibility
- Updated dependencies for Minecraft 1.20.1
- Maintained mod integrations and API compatibility

## Dependencies

This project uses:

- Forge 1.20.1
- Cloth Config API
- The One Probe
- Curios API

All dependencies are adapted for their Forge 1.20.1 versions.
