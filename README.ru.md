Порт Industrial Craft Classic для **Minecraft Forge 1.20.1**.

Этот проект является неофициальным продолжением и портом **Industrial Craft Classic** с Minecraft **1.19.2 Forge** на **1.20.1 Forge**.

Главная цель проекта — сохранить оригинальный игровой процесс, API, механики и совместимость, адаптировав мод под новые версии Minecraft и Forge.

## Возможности

- Полноценный опыт Industrial Craft Classic для Forge 1.20.1
- Сохранение машин и энергетических систем
- Сохранение предметов, блоков и игровых механик
- Обновлённая совместимость с Forge API
- Обновлённые зависимости для Minecraft 1.20.1
- Сохранение интеграций с другими модами и совместимости API

## Зависимости

Этот проект использует:

- Forge 1.20.1
- Cloth Config API
- The One Probe
- Curios API

Все зависимости адаптированы под их версии для Forge 1.20.1.
